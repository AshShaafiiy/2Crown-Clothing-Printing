# Business Rules

## 1. Custom Work Flow
- **Navigation**: Normal navigation links reset the page scroll to the top. However, clicking "Custom Work" in the Navbar or Footer smoothly scrolls the user to the `#custom-work` section on the Homepage. It does **not** directly open WhatsApp.
- **CTA**: Only the button inside the `#custom-work` section natively triggers the WhatsApp popup.
- **No File Uploads**: Customers do NOT upload custom design files, logos, or reference images to the website. The website contains zero customer file storage. All materials must be sent by the customer directly through WhatsApp.
- **Custom Order Form**: There is no dedicated custom order form on the website.

## 2. Product Ordering & Cart
- The normal storefront flow (Shop → Product → Cart → Checkout) must remain entirely separate from the Custom Work inquiry flow.
- If a customizable product requires a file (e.g., Logo), the website must **not** render a file input. It must display an informational note instructing the user to send the file on WhatsApp. The item must be valid to add to the cart without file data.

## 3. Delivery
- **Store Pickup**: Free (`₦0`). The order's Estimated Total is exactly the product subtotal.
- **Local Delivery**: The website does **not** calculate, estimate, or assume delivery fees. The customer provides their address, and 2Crown manually determines the cost later.
- **WhatsApp Message format for Local Delivery**:
  - `Delivery Fee: To be confirmed`
  - `Estimated Total: ₦[subtotal] + delivery`
  - It explicitly instructs the customer to: *"Please confirm the final price and delivery arrangements."*

## 4. WhatsApp Centralization
- **Number**: The official business WhatsApp number is `+234 906 174 7646` (Normalized to `2349061747646`).
- **Source of Truth**: All WhatsApp links generated by the application must securely pull this number from the `BusinessSettings` object (`services.settings.getBusinessSettings()`). Hardcoding the number in components is forbidden.

## 5. Rating System
- The feedback system is **Star-Rating Only** (1 to 5 stars).
- There is no written customer review functionality.
- The UI terminology must strictly use "rating", "ratings", or "Rate this product". The word "review" is forbidden in customer-facing UI.

## 6. Admin Media
- Admin-managed website media (product thumbnails, gallery images, promotional banners) remains supported and is structurally different from customer file storage.

## 7. Homepage Sections
- **Approved**: Hero, Featured Products, Services, Custom Work (Need Something Custom?).
- **Removed (Do Not Reintroduce)**: Shop by Category, How Custom Orders Work, Testimonials (What Our Clients Say).
